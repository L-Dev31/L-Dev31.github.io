The Brief

In late 2026, I started translating the Japan-only Nintendo DS game Tomodachi Collection into French. All of its text sits inside BMG files, an undocumented, proprietary Nintendo format. The few fan-made tools available were unreliable and kept corrupting my saves.

I needed a tool that worked, so I built a browser-based BMG editor. It opens, edits and re-exports files and keeps every original byte it has no reason to change.

A hex editor, a lot of trial and error, and no documentation or SDK.

The Problem

Locked Files, Broken Tools

Nintendo uses the BMG format for dialogue across many DS and Wii games, and never released a public spec. Community editors existed, but they often crashed the game by breaking offset tables or padding rules.

Tomodachi Collection adds raw hex control tags inside its text strings, to trigger colors or insert Mii names. An editor that didn't understand them stripped them out, and the file broke.

The Process

1. Reverse-Engineering the Format

I opened the files in a hex editor and mapped the structure by hand. A BMG file is split into chunks: a header, an index of message sizes, the raw text block, and numeric IDs that tell the game where to find each string.

2. Parsing Inline Tags

The inline control tags were the hardest part. The editor shows them as readable text like [Color:0200] and encodes them back on save. Existing tags reuse their original bytes, and only tags you type yourself get new hex codes. This nearly removes the risk of corruption.

3. Non-Destructive Export

The export rule is simple: only touch what changed. A message you didn't edit keeps its original bytes. A message you edited is re-encoded and padded, and the index is updated to point to the new location. Everything else stays as it was.

4. Game-Specific Profiles

Every Nintendo game handles BMG files a little differently. Instead of hardcoding the rules for Tomodachi Collection, I built a plugin system: pick the game from a menu and the editor loads the right tag vocabulary and styling.

The Design

5. Visual Language

The interface leans on #FDE404, the signature yellow of Tomodachi Collection. Translation means reading text for hours, so I chose a dark, low-contrast background to limit eye strain.

6. Workflow Decisions

Translating a game means handling hundreds of files, and opening them one by one is slow. I added a folder mode to load a whole directory, and keyboard shortcuts for every action, so the editor works as a daily workspace.

The editor leaves a Mii name alone because it only touches the bytes that changed.

The Outcome

A translation side project became a complete browser-based binary editor for a closed console format. It parses, edits and rebuilds these files safely, without any official documentation.
