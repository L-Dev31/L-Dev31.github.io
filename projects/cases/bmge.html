The Brief

In late 2026, I decided to translate the Japan-exclusive Nintendo DS game Tomodachi Collection into French. The game keeps all its text locked inside BMG files. It is an undocumented, proprietary Nintendo format. The few fan-made tools out there were unreliable and kept silently corrupting my saves.

I needed a tool that actually worked, so I built a browser-based BMG editor from scratch. It opens, edits, and re-exports files while preserving every single original byte it does not strictly need to touch.

No documentation. No SDKs. Just a hex editor and a lot of trial and error.

The Problem

Locked Files, Broken Tools

Nintendo uses the BMG format for dialogue across various DS and Wii games, but they never released a public spec. Community editors existed but they constantly crashed the game engine by messing up offset tables or padding rules.

Tomodachi Collection makes this even harder by embedding raw hex control tags directly inside text strings to trigger colors or insert Mii names. If an editor did not understand these tags, it stripped them out. The result was a broken file.

The Process

1. Reverse-Engineering the Format

I opened the files in a hex editor and mapped the structure by hand. A BMG file is split into specific chunks: a header, an index for message sizes, the raw text block, and numeric IDs so the game knows exactly where to look for a string.

2. Parsing Inline Tags

Those inline control tags were the real headache. My editor translates them into readable text like [Color:0200]. When you save your work, the tool re-encodes them perfectly. It reuses the exact original bytes for existing tags and only generates new hex codes for tags you type yourself. This practically eliminates corruption risks.

3. Non-Destructive Export

The export logic is simple: only touch what changed. If you do not edit a message, the tool leaves its original byte chunk alone. If you edit something, it gets re-encoded and padded, and the file's index updates to point to the new location. Every other part of the binary data stays exactly as it was.

4. Game-Specific Profiles

Every Nintendo game handles BMG files a bit differently. Instead of hardcoding the rules just for Tomodachi, I built a plugin system. You just pick the game from a dropdown menu and the editor loads the correct tag vocabulary and visual styling.

The Design

5. Visual Language

The UI leans heavily on #FDE404, the signature yellow from Tomodachi Collection. Since translation work means staring at text for hours on end, I went with a dark, low-contrast background to cut down on eye strain.

6. Workflow Decisions

Translating a game means juggling hundreds of files. Opening them one by one is miserable. I added a folder mode so you can load entire directories at once, plus keyboard shortcuts for everything. I wanted a workspace you could actually live in.

The editor does not need to know what a Mii is. It just knows exactly which bytes to leave alone.

What This Built

What started as a translation side project turned into a full browser-based binary editor for a closed console format. It safely parses, edits, and rebuilds these files without any official documentation. It was a solid exercise in staring at raw bytes until the underlying structure finally made sense.
