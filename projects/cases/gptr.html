The Brief

In 2023, as a first-year student at Lycée Sonny Rupaire in Sainte-Rose, Guadeloupe, I entered the Trophées NSI, a competition where high school students build a project in Python. I was living in Guadeloupe without being Guadeloupean. Every day I heard Guadeloupean Creole around me and understood nothing, which was isolating.

The idea came from there: a tool I would use myself. With my classmate Korail Lamothe-Jacob, who grew up speaking Creole, we decided to build the first French ↔ Guadeloupean Creole translator. We wanted something usable every day.

The language was everywhere. The tools to understand it did not exist, so we built them.

The Problem

A Language With No Digital Footprint

Guadeloupean Creole is spoken by hundreds of thousands of people, yet it has no mainstream dictionary, translation API or structured dataset. We searched online, in libraries and in academic sources, and found no bilingual wordlist or corpus a program could use. We nearly abandoned the project.

After weeks of searching, I found one old database of Guadeloupean terms, unmaintained and buried. It was incomplete, inconsistent and full of errors, but it was the only one. We took it.

The Process

1. Building the Dataset

Korail and I went through the recovered database entry by entry. He corrected the Creole terms, and I restructured everything into a clean JSON dictionary we could query. It isn't perfect, since Guadeloupean Creole has no standardized spelling, but every entry was checked by a native speaker, not generated. That dictionary became the foundation of the algorithm.

2. The Translation Algorithm

Translating natural language into a low-resource language is hard because phrases rarely have direct equivalents, and a word-for-word lookup fails immediately.

So the algorithm takes the full sentence and looks for the longest substring that matches the dictionary. If it finds one, it translates that span and moves past it. If not, it drops one word from the right and tries again. If it ends on a single word with no match, it leaves that word as it is and restarts from the next one.

The result favors phrase-level accuracy over broken word-for-word substitution.

3. Interface & Bidirectional Translation

The tool works in both directions, French to Creole and Creole to French. The interface uses Tkinter, so it runs without installation, with an input field, a language selector, a translate button and an output display. Everything runs locally and offline, because a tool meant for school computers in Guadeloupe could not depend on an internet connection.

We built a tool from nothing, for a language the internet had left out.

The Outcome

A Python desktop application that translates in both directions between French and Guadeloupean Creole, using a hand-corrected bilingual JSON dataset and a greedy longest-match algorithm written without an NLP library. The jury gave it a special selection, outside the top prizes, for tackling a problem with no existing solution.

What I took from it: finding data nobody had gathered was harder than writing the code.
